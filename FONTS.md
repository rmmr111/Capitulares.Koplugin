# Tipos de letra recomendados para capitulares

O plugin **Capitulares** procura prioritariamente fontes ornamentais em `.adds/koreader/fonts/Initials/`.
As fontes **não são fornecidas** com o plugin. Descarrega-as dos respetivos autores/distribuidores e lê a licença antes de as utilizar ou redistribuir.

| **Pirata One** | Gótico de destaque, contrastado | https://fonts.google.com/specimen/Pirata+One |

**Nota:** as fontes do Google Fonts não são necessariamente «iluminuras» com desenho interior à letra. Para esse efeito, começa por Mosaic Initials ou Goudy Initialen. O plugin pode normalizar iniciais acentuadas quando o tipo de letra ornamentado não contém o respetivo glifo; o texto original é preservado.

### Instalação no Kobo

1. Descarrega a fonte no formato **TTF ou OTF**.
2. Copia-a para `.adds/koreader/fonts/Initials/` (cria a pasta `Initials`, se necessário).
3. Reinicia o KOReader para carregar a lista de fontes.
4. No EPUB: **Ferramentas → Capitulares → Personalizar capitular → Initials**.
5. Experimenta primeiro no EPUB de teste; algumas fontes decorativas contêm poucas letras ou não são reconhecidas pelo motor.

**Licenças:** https://openfontlicense.org/ explica a OFL, mas os direitos de cada fonte são definidos pela licença que a acompanha. Não incluímos fontes de terceiros no pacote Capitulares.
